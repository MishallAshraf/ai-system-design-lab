# AI System Design Lab

My hands-on record of a 72-topic course on designing production AI systems, built around **Ustaad**, a bilingual (English and Urdu) AI tutoring platform for schools and tutors.

Every topic here has three things: working code, a measured result, and a one-page note in my own words.
